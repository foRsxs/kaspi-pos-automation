Настройки сервера

Учётная запись

Вход выполнен как admin.

Изменить пароль

Используйте не менее 12 символов. Длина пароля — до 128 символов.

Ключ шифрования

TOKEN_SECRET_KEY используется для защиты данных на сервере.

Проверяем…

Сервер автоматически хранит TOKEN_SECRET_KEY в конфигурации. Значение скрыто. Его замена требует перешифрования сохранённых данных.

Уведомления о подключении

Получайте письма, если счёт Kaspi Pay нужно подключить заново.

Проверяем…

Настройка действует для всех проектов. Сервер проверяет подключение раз в 5 минут и отправляет одно письмо на каждый случай подтверждённой потери подключения. Сбой сети сам по себе не отправляет такое письмо.

Уведомления выключены

Укажите один адрес. Включение возможно после заполнения параметров почтового сервера.

Почтовый сервер

Пароль не показывается. Пустое поле сохраняет его, только если сервер и имя пользователя не менялись.

Если очистить имя пользователя, сохранённый пароль SMTP будет удалён.

Последнее письмо: не отправлялось

Ошибок отправки нет.

Тест использует только сохранённые настройки. Приём письма почтовым сервером не гарантирует доставку во входящие.

Ключ администратора API

Проверяем состояние ключа…

Перевыпуск немедленно отключит прежний ADMIN_API_KEY. Обновите все интеграции новым ключом.

ПОДТВЕРЖДЕНИЕ

Перевыпустить ключ администратора?

Текущий ADMIN_API_KEY сразу перестанет работать. После подтверждения скопируйте новый ключ и обновите все интеграции.

Оставьте поле пустым, чтобы сервер сгенерировал ключ.

HTTP 2xx означает, что сервер получателя принял запрос, но не подтверждает бизнес-обработку события. Повторная доставка использует тот же X-Webhook-ID: обработчик получателя должен учитывать дубликаты. Старые доставки, удалённые до включения журнала, здесь не восстанавливаются.

ПОВТОРНАЯ ДОСТАВКА

Поставить доставку в очередь?

Запрос не отправляется напрямую: доставка будет поставлена в очередь с прежним X-Webhook-ID. Получателю нужно безопасно обработать повтор. Ответ HTTP 2xx подтверждает только приём запроса сервером получателя, а не бизнес-обработку.
